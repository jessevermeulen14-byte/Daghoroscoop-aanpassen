# Daghoroscoop 00:00

Gratis Android-app die iedere nacht om 00:00 probeert de geïnstalleerde app CW-daghoroscoop te openen, en automatisch het volgende alarm plant. Geen server of abonnement.

**Android-beperking:** op een vergrendeld toestel kan Android het openen van een andere app vanuit de achtergrond blokkeren. In dat geval verschijnt (mits toegestaan) een melding. Dit is niet te omzeilen met een gewone Android-app.

Na installatie: open deze app één keer, controleer met de testknop of CW-daghoroscoop gevonden wordt, en verleen indien gevraagd toestemming voor exacte alarmen en meldingen. Op Samsung kan onbeperkt batterijgebruik nodig zijn. Een web-snelkoppeling is geen gewone geïnstalleerde app; dan is de URL nodig.

Bouwen: koppel deze repository aan Codemagic en start workflow android-debug. Deze broncode is nog niet op een Samsung getest.
